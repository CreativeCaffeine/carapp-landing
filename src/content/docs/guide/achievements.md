## 実績・称号を集める

ドライブや記録を続けると、自動的に **実績（アチーブメント）** が解除されます。称号を獲得して、自分のカーライフをコレクションしましょう。

![実績画面](/carapp-landing/screens/achievements.png)

### 実績の種類

| タイプ | 例 |
|-------|---|
| **走行距離** | 累計100km / 1,000km / 10,000km / 50,000km 達成 |
| **ドライブ回数** | ドライブ10回 / 50回 / 100回 |
| **給油回数** | 給油10回 / 50回 |
| **メンテナンス回数** | 整備記録20回 / 50回 |
| **エリア** | 47都道府県走破 |
| **特殊** | 雨の日ドライブ、夜間ドライブ、長距離ドライブなど |

### 称号の付与

特定の実績を解除すると **称号** がもらえることがあります。称号は車両プロフィールに表示され、車両一覧でも確認できます。

例：
- 「東海道完走」: 東京〜大阪を1ドライブで走破
- 「燃費マスター」: 累計平均燃費が一定値以上
- 「夜の走り屋」: 22時以降のドライブを N 回達成

### 実績の確認

ホーム画面の「実績」セクション、または設定画面の「実績一覧」から、未解除の実績ヒントも確認できます。

:::tip
実績はローカルで自動計算されます。サーバーへのデータ送信は不要です。記録を続けるだけで、勝手に解除されていきます。
:::
