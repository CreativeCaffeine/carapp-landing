## 手続き・書類を記録する

車に関する **公的手続きや書類のやり取り** を記録するカテゴリです。

![汎用記録フォーム](/carapp-landing/screens/generic-form.png)

### サブカテゴリ

| サブカテゴリ | 主な記録項目 |
|------------|------------|
| 車検証更新 | 旧/新車検期限、実施場所 |
| リコール対応 | リコール番号、対応日、対応内容 |
| 名義変更 | 旧/新所有者、実施日、書類保管場所 |
| 住所変更 | 旧/新住所、実施日 |
| 廃車手続き | 実施日、業者、書類保管場所 |
| 譲渡・売却 | 売却先、金額、書類保管場所 |
| その他 | 自由記入 |

### 記録できる項目（共通）

- 実施日
- 場所・窓口
- 関連書類の写真（OCR非対応・画像保存のみ）
- メモ

### このカテゴリの位置づけ

車を売却・廃車にするときに必要な書類の所在を、写真とメモでひも付けて保管できます。「あの書類どこにしまったっけ？」を防ぐためのカテゴリです。

:::tip
リコール通知が届いたら、対応前にこのカテゴリで「リコール番号」を記録しておくと、対応後に履歴として参照できます。
:::
