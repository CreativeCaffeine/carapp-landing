## 手続き・書類を記録する

車に関する **公的手続きや書類のやり取り** を記録するカテゴリです。

![手続き・書類の記録フォーム](/carapp-landing/screens/documents-form.png)

### サブカテゴリ

| サブカテゴリ | 主な記録項目 |
|------------|------------|
| 車検（書類） | 車検証の有効期間（開始日 / 終了日）、担当先 |
| リコール対応 | リコール番号、対応日、対応内容 |
| 名義変更 | 旧/新所有者、実施日、書類保管場所 |
| 住所変更 | 旧/新住所、実施日 |
| 廃車手続き | 実施日、業者、書類保管場所 |
| 譲渡・売却 | 売却先、金額、書類保管場所 |
| その他 | 自由記入 |

:::tip
書類カテゴリの「車検」は **車検証の有効期間管理** が目的です。整備実績（工賃・法定費用・作業内容）を残したい場合は、メンテナンスカテゴリ側の「[車検整備](/carapp-landing/guide/maintenance/)」をご利用ください。
:::

### 記録できる項目（共通）

- 実施日
- 場所・窓口
- 関連書類の写真（OCR非対応・画像保存のみ）
- メモ

### このカテゴリの位置づけ

車を売却・廃車にするときに必要な書類の所在を、写真とメモでひも付けて保管できます。「あの書類どこにしまったっけ？」を防ぐためのカテゴリです。

:::tip
リコール通知が届いたら、対応前にこのカテゴリで「リコール番号」を記録しておくと、対応後に履歴として参照できます。
:::
