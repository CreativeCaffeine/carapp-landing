## メンテナンス・整備を記録する

くるまのカルテは、車に関するあらゆる整備記録に対応した **11種類のサブカテゴリ** を用意しています。それぞれ専用フィールドが用意されているので、後から見返したときに必要な情報が抜けません。

![整備記録フォーム](/carapp-landing/screens/maintenance-form.png)

### サブカテゴリ一覧

| サブカテゴリ | 主な記録項目 |
|------------|------------|
| 定期点検 | 点検種別（3/6/12ヶ月）、実施場所、次回点検予定日・距離、作業内容 |
| 車検 | 実施場所、次回車検期限、法定費用、工賃、作業内容 |
| 修理 | 修理箇所、部品名・部品番号、保証期限、症状メモ |
| 板金塗装 | 実施場所、施工箇所、保証期限 |
| タイヤ交換 | タイヤ種別（ノーマル/スタッドレス）、ブランド、サイズ、本数、製造年週(DOT)、次回交換目安距離 |
| バッテリー交換 | 型番、ブランド、保証期限 |
| 部品購入 | 品名、メーカー、品番、保管場所 |
| オイル交換 | オイル銘柄、粘度、量、フィルター交換有無 |
| 洗車・コーティング（→ [洗車を記録する](/carapp-landing/guide/wash/)） | 別カテゴリ |
| カスタム・ドレスアップ | 内容、施工場所 |
| その他 | 自由記入 |

### 車検証OCR

新車登録・車検時には、車検証をカメラで撮影すると以下が自動入力されます。

- 次回車検期限
- 法定費用（自賠責・重量税・印紙代）
- 車両情報

詳しくは「[OCRで読み取る](/carapp-landing/guide/ocr/)」をご覧ください。

### 写真添付

各記録には作業明細・部品レシート・施工前後の写真を複数枚添付できます。後から「あのとき何のオイルを入れたか」を確認するのに便利です。

:::tip
タイヤ交換やバッテリー交換のように **次回交換目安** が決まっているメンテは、「[リマインダー](/carapp-landing/guide/reminders/)」を設定しておくと交換時期にプッシュ通知が届きます。
:::
