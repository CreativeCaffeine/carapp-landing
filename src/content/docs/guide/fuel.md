## 給油・充電を記録する

ガソリン車・ディーゼル車・EV のいずれにも対応。記録を続けると **平均燃費（km/L）** や **電費（km/kWh）** が自動計算されます。

![給油記録フォーム](/carapp-landing/screens/fuel-form.png)

### 給油記録の項目

| 項目 | 内容 |
|------|------|
| 給油量 | リットル単位（小数点入力可） |
| 単価 | 円/L |
| 合計金額 | 給油量 × 単価から自動計算 |
| 満タン給油 | チェックすると次回までの燃費計算対象になる |
| 店舗名 | 例：エネオス 品川SS |
| 走行距離（ODO） | 燃費計算に使用 |

### EV 充電の記録項目

充電サブカテゴリでは EV 専用フィールドを記録できます。

- 充電量（kWh）
- 単価（円/kWh）
- 充電タイプ（急速 / 普通）
- 開始 SOC・終了 SOC（%）
- 充電時間
- 充電スポット名

### 燃費の自動計算

満タン給油同士の間の走行距離 ÷ 給油量 で **平均燃費** を算出します。途中の継ぎ足し給油は集計対象外なので、正確な燃費を知りたい場合は **満タン給油** にチェックを入れて記録してください。

平均燃費はホーム画面と統計画面で確認できます。

### 入力ミスを防ぐ仕組み

給油記録は入力ミスを早めに検知できるよう、以下のチェックを行います。

- **給油量**: 0 〜 200 L の範囲外、または非数値の場合はエラー表示
- **単価**: 0 〜 1000 円/L の範囲外、または非数値の場合はエラー表示
- **走行距離（ODO）**: 直近の記録より小さい値を入力した場合、新規作成時に確認ダイアログが表示されます（タイプミスや単位間違いを検知）

:::tip
レシートをカメラで撮影すれば、給油量・単価・金額・店舗名を AI が自動で読み取ります。詳しくは「[OCRで読み取る](/carapp-landing/guide/ocr/)」をご覧ください。
:::
