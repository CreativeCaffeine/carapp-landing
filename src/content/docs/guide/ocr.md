## OCRで読み取る

くるまのカルテは、レシートや車検明細をカメラで撮影するだけで、AIが自動的に金額・日付・項目を読み取ります。

### 使い方

1. 記録の追加画面で **カメラアイコン** をタップ
2. 撮影方法を選択：
   - **カメラ**: その場で撮影
   - **ギャラリー**: 保存済みの写真から選択
   - **PDF**: PDFファイルから読み取り
3. AIが自動的に内容を解析
4. 読み取った内容が各フィールドに自動入力されます
5. 必要に応じて修正し、保存

### 読み取れるもの

| 書類 | 読み取れる項目 |
|------|--------------|
| ガソリンスタンドのレシート | 給油量・単価・合計金額・日付 |
| 車検の明細書 | 費用内訳・合計金額・日付 |
| メンテナンスの領収書 | 作業内容・金額・日付 |
| 税金の納付書 | 税額・納付日 |

### うまく読み取れないとき

- **明るい場所で撮影**してください。暗いと認識精度が下がります
- **書類を平らに置いて**、できるだけ真上から撮影してください
- **文字が切れないように**、書類全体が写るようにしてください
- 読み取り後の内容は必ず確認し、間違いがあれば手動で修正してください

:::note
OCR機能はインターネット接続が必要です。読み取り処理にはAI（Gemini）を使用しています。
:::
