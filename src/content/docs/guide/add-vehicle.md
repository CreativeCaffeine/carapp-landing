## 車両を登録する

ぶんぶんノートでは、複数の車両を登録して切り替えることができます。

### 新しい車両の登録

1. 初回起動時は自動的に登録画面が表示されます
2. 2台目以降は **設定** → **登録車両** から追加できます

### 入力する情報

#### 基本情報

| 項目 | 必須 | 説明 |
|------|------|------|
| 車名 | はい | 車の名前やニックネーム |
| メーカー | いいえ | トヨタ、ホンダなど |
| 年式 | いいえ | 初年度登録年 |
| ナンバー | いいえ | 「品川 300 あ 12-34」など |
| 型式 | いいえ | 「ZVW50」などの型式コード |
| 走行距離 | いいえ | 現在のオドメーター値（km） |

#### 詳細情報（折りたたみ）

| 項目 | 内容 |
|------|------|
| 駆動方式 | FF / FR / MR / RR / 4WD |
| ミッション | AT / CVT / MT |
| 油種 | レギュラー / ハイオク / 軽油 / 電気 |
| 排気量 | cc |
| 車両重量 | kg |
| 初度登録年月 | 「2020/10」など |
| 車検満了日 | 「2026/10/15」など |

#### 購入情報（折りたたみ）

| 項目 | 内容 |
|------|------|
| 購入日 | 「2022/04/15」など |
| 本体価格 | 円 |
| 諸経費 | 円 |
| 借入額 / 月々 / 金利 / 期間 | ローン情報 |
| 下取り / 値引き | 円 |

:::tip
**車検証OCR** を使えば、型式・初度登録年月・車両重量・排気量・駆動方式などをまとめて自動入力できます。詳しくは「[OCRで読み取る](/carapp-landing/guide/ocr/)」をご覧ください。
:::

### 車両の切り替え

ホーム画面上部の車両名をタップすると、登録済みの車両一覧が表示されます。切り替えたい車両を選択してください。

:::tip
家族で複数台の車を持っている場合、それぞれ登録しておくと車ごとの維持費を個別に管理できます。
:::
