## プレミアムプラン

ぶんぶんノートは **基本機能を無料で** 使えます。さらに便利に使いたい方向けに、プレミアムプランをご用意しています。

![プラン画面](/carapp-landing/screens/subscription.png)

### プランの違い

| 機能 | 無料 | プレミアム |
|------|:---:|:---:|
| 車両登録 | 1台 | 無制限 |
| 給油・整備・洗車記録 | ✅ | ✅ |
| ドライブ記録 | ✅ | ✅ |
| OCR レシート読み取り | 月3回まで | 月30回まで |
| 統計・グラフ | 基本 | 詳細・期間比較 |
| データエクスポート（CSV / PDF） | ❌ | ✅ |
| 広告非表示 | ❌ | ✅ |

※具体的な制限値はアプリ内の最新情報をご確認ください。

### 課金について

- 課金は **RevenueCat** を経由して App Store / Google Play で処理されます
- サブスクリプションの解約は、各ストアの設定画面から行えます
- 一度購入したプランは、ストアの「購入の復元」機能で別端末でも引き継ぎできます

### プレミアムにアップグレードする

設定画面の「プレミアムプラン」から、現在のプラン状況の確認とアップグレードができます。

:::tip
データの所有権はあなたにあります。プレミアムを解約しても、これまでの記録はすべて端末に残ります。再課金や別アプリへの乗り換えで困ることはありません。
:::
