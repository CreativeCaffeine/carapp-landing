## 洗車・車内清掃を記録する

洗車・コーティング・車内清掃の記録を残しておくと、次に洗車したくなる頃合いがわかりやすくなります。

### サブカテゴリ

| サブカテゴリ | 内容 |
|------------|------|
| 洗車 | 手洗い / 機械洗車、コーティング・ワックスのオプション、店舗名、費用 |
| 車内清掃 | 内装清掃、シャンプー、消臭などの記録 |

### 記録できる項目

- 洗車日時
- 種別（手洗い / 機械洗車 / コイン洗車）
- コーティングの種類（ガラス / ポリマー / なし など）
- 費用
- 実施場所
- メモ・写真

### 統計への反映

洗車回数はホーム画面の「最後の洗車から○日」のカウンターと、統計画面の **洗車履歴グラフ** に反映されます。

:::tip
ホーム画面では「最後の洗車から○日経ちました」が常時表示されます。雨が続く季節や黄砂・花粉の時期にも便利な目安になります。
:::
