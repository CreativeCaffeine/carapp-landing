## 機能一覧

くるまのカルテで管理できる機能を、カテゴリごとに俯瞰できます。それぞれのページで詳しい使い方を確認してください。

![ホーム画面](/carapp-landing/screens/home.png)

### 車両・記録

| 機能 | 内容 |
|------|------|
| [車両を管理する](/carapp-landing/guide/vehicles/) | 複数台の登録、車検証OCR、車両画像 |
| [給油・充電を記録する](/carapp-landing/guide/fuel/) | ガソリン・EV両対応、燃費の自動計算 |
| [メンテナンスを記録する](/carapp-landing/guide/maintenance/) | 11種類のサブカテゴリで詳細記録 |
| [洗車を記録する](/carapp-landing/guide/wash/) | 洗車・車内清掃の履歴 |
| [税金・保険を記録する](/carapp-landing/guide/insurance-tax/) | 自動車税・自賠責・任意保険 |
| [高速料金・駐車場代](/carapp-landing/guide/trip-expense/) | 走行距離不要の素早い記録 |
| [手続き・書類を記録する](/carapp-landing/guide/documents/) | 車検証更新・リコール・名義変更 |

### ドライブ・移動

| 機能 | 内容 |
|------|------|
| [ドライブを記録する](/carapp-landing/guide/drive/) | GPS追跡・スコア・思い出 |
| [自動記録を設定する](/carapp-landing/guide/auto-record/) | Bluetooth/iBeaconトリガー |

### 入力支援

| 機能 | 内容 |
|------|------|
| [OCRで読み取る](/carapp-landing/guide/ocr/) | レシート・車検証の自動入力 |

### サマリー・通知

| 機能 | 内容 |
|------|------|
| [費用を確認する](/carapp-landing/guide/stats/) | 月次・年次の維持費グラフ |
| [リマインダーを設定する](/carapp-landing/guide/reminders/) | 期間・距離ベースの通知 |
| [実績・称号](/carapp-landing/guide/achievements/) | 走行距離・回数で解除 |

### その他
