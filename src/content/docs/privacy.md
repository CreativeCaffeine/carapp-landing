CreativeCaffeine（以下「運営者」）は、アプリ「ぶんぶんノート」（以下「本アプリ」）で扱う情報について、次のとおり定めます。

## 基本的な考え方

- 本アプリにアカウント登録やログインはありません。氏名、メールアドレス、電話番号の入力を求めません。
- 記録したデータは、お使いの端末の中に保存します。運営者のサーバーには送信しません。
- 一部の機能では、下の「外部に送信する情報」に書いた範囲で、外部のサービスに情報を送ります。

## 端末内に保存する情報

次の情報は端末内にだけ保存します。

- 車両の情報（車名、年式、走行距離、写真など）
- 給油、充電、整備、洗車、税金、保険、高速料金、駐車場代などの記録と、添付した写真
- ドライブ記録（走行ルートの位置情報、日時、距離、所要時間）
- リマインダーとアプリの設定

## 外部に送信する情報

### AI による読み取りと提案（Google Gemini API）

次の機能を使ったときに、Google の Gemini API へ情報を送ります。使わなければ送りません。

| 機能 | 送る情報 |
|------|----------|
| レシートの読み取り | 撮影または選択したレシートの画像 |
| 車検証の読み取り | 撮影または選択した車検証の画像 |
| リマインダーの提案 | 車名、年式、走行距離、車種、提案を求めるメンテナンス項目の名前 |
| ドライブタイトルの生成（プレミアム） | ドライブの日時、距離、所要時間。位置情報は送りません |

車検証の画像には、所有者や使用者の氏名と住所が写ります。本アプリが読み取り結果として取り出すのは車両の情報だけですが、画像はそのまま送信します。

本アプリは Gemini API の有料サービスを使っています。Google の規約では、有料サービスに送られた内容（画像を含みます）と応答を、Google は自社の製品の改善に使いません。不正な利用の検知と防止、および法令上必要な開示のために、Google が内容を一定の期間記録することがあります。詳しくは [Gemini API 追加利用規約](https://ai.google.dev/gemini-api/terms)をご覧ください。

### 広告（Google AdMob）

無料プランでは広告を表示します。広告の配信のために、Google の AdMob が次の情報を取得することがあります。

- 広告ID などの端末の識別子
- IPアドレスと、そこから推定されるおおよその位置
- 広告の表示やタップなどの情報、端末と OS の情報

iOS では、トラッキングの許可を求める画面で許可した場合にだけ、広告用の識別子（IDFA）を使います。許可しなくても、すべての機能を使えます。地域によっては、広告に関する同意の画面を表示します。

プレミアムプランでは広告を表示しません。

### 購入の管理（App Store、Google Play、RevenueCat）

プレミアムプランの購入と状態の確認には、App Store または Google Play と、RevenueCat を使います。RevenueCat には、購入の履歴と、アプリが発行する匿名の ID が送られます。クレジットカードなどの支払い情報を、運営者が受け取ることはありません。

### 地図の表示（Google マップ）

ドライブ記録の地図は Google マップで表示します。

地図を表示するとき、表示する範囲の地図データを取得するために、端末から Google のサーバーへ通信します。表示している範囲は Google に伝わります。この通信に伴って、Google は次の情報を取得することがあります。

- IPアドレス、端末と OS の情報
- 地図の操作などの利用状況
- クラッシュや動作の速さなどの診断情報
- 端末やアプリに割り当てた識別子

本アプリが記録した走行ルートは端末の中に保存し、運営者のサーバーには送りません。

## 端末の機能の利用

| 機能 | 使う目的 |
|------|----------|
| 位置情報 | ドライブの走行ルートと距離の記録。自動記録を有効にすると、アプリを開いていないときも記録します |
| Bluetooth | 車に置いた iBeacon の検出。Android では、車の Bluetooth 機器への接続の検出にも使います |
| カメラ、写真 | レシートと車検証の読み取り、車両や整備の写真の添付 |
| 通知 | リマインダーと、ドライブ記録中の表示 |

位置情報は端末内にだけ保存し、外部には送信しません。

## 利用目的

取得した情報は、次の目的にだけ使います。

- 本アプリの機能の提供（記録、読み取り、提案、リマインダー）
- プレミアムプランの購入状態の確認
- 広告の配信（無料プラン）
- お問い合わせへの対応

## 第三者への提供

上に書いた外部サービスへの送信を除き、情報を第三者に提供しません。ただし、法令に基づく場合を除きます。

## データの書き出しと削除

- 書き出し。「設定」の「プライバシー」にある「データをエクスポート」から、記録を書き出せます。
- 削除。「設定」の「プライバシー」にある「アカウントデータを削除」から、端末内のすべてのデータを削除できます。

運営者はデータを預かっていないため、運営者の側で削除や開示を行うデータはありません。
